# @lastly/parser

한국어 한 문장에서 **LLM 없이** 뽑아내는 규칙. `web` 과 `api` 가 함께 쓴다.

해석에 필요한 다섯 가지 중 넷은 말의 형태만 보면 정해진다. 그 넷을 먼저 처리해 두면
LLM 까지 가는 문장이 크게 줄고, 무료 호스팅의 콜드 스타트도 타지 않는다.

---

## 추출 항목

`readUtterance(text, reference)` 하나가 아래를 한 번에 돌려준다.

| 필드 | 예 |
|---|---|
| `intent` | "언제 빨았지?" → `query`, 그 밖 → `record` |
| `daysAgo` | "지난주 일요일" → 기준일 요일로 계산 |
| `statedCadenceDays` | "세달에 한번" → 90 · "이틀에 한번" → 2 |
| `name` | "수건 빨았어" → "수건 빨래" |
| `sawDate` · `sawAction` | 문장에서 읽어낸 값인지 여부. 확신도 산정에 쓴다 |

조각으로도 쓸 수 있다 — `readIntent` · `readDaysAgo` · `readCadenceDays` · `readName`.

**`sawAction` 이 false 면 `name` 을 믿지 않는다.** "음 그러니까 그거" 같은 문장도
지우고 나면 뭔가 남기 때문이다.

---

## 어휘 설계

대상("가습기 필터", "블라인드")은 끝이 없지만 행동은 유한하다. 대상을 건드리지 않으므로
처음 보는 물건도 사전에 있을 필요가 없다. 넓힐 때는 `ACTION_NOUNS` 에 한 줄 더한다.

행동은 두 종류다.

| | 예 | 이름 결과 |
|---|---|---|
| 동사 | 빨다 · 갈다 · 닦다 · 깎다 · 채우다 | "수건 빨았어" → 수건 빨래 |
| 동작성 명사 | 설거지 · 분리수거 · 세차 · 환기 · 산책 | "설거지 했어" → 설거지 |

동작성 명사를 빠뜨리면 이름은 맞게 나오는데 `sawAction` 이 서지 않아 규칙이 자기 답을
믿지 못하고 LLM 으로 넘어간다. 새 행동을 더할 때 어느 쪽인지 먼저 가린다.

**정확도** — 평가 문장 100개에서 이름 확정 100건. 같은 과제에서 호스팅 LLM 은
30문장 중 25건이었다. 답이 하나로 정해지는 문제라 규칙이 유리하고, 틀리면 한 줄
고쳐 테스트로 고정할 수 있다.

---

## 분리 배경

연결이 끊긴 브라우저가 같은 규칙을 써야 하기 때문이다. 오프라인에서 항목·날짜·주기를
정하려면 같은 코드가 양쪽에서 돌아야 하고, 구현을 두 벌로 두면 오프라인 결과가
온라인과 갈린다.

```
api   byRules()                    평소 경로. 규칙으로 풀리면 LLM 을 부르지 않는다
web   lib/offline/resolve-offline  연결이 없을 때만. 같은 함수를 브라우저에서 돌린다
```

---

## 출력 어휘와 주기 사전

`cadence_priors.canonical_name` 은 이 파서가 만들어내는 이름과 같은 형태여야 한다.
어긋나면 사전에 값이 있어도 조회되지 않고 기본값 2주로 떨어진다.

```
파서 출력    <대상> + <행동 명사>     예) 베갯잇 빨래
사전 키      같은 형태                예) 베갯잇 빨래   (베갯잇 세탁 아님)
```

`ACTION_NOUNS` 는 세탁·빨래·빨았다를 모두 `빨래` 하나로 모은다. 사전에 `… 세탁` 으로
넣으면 닿지 않는다. **행동 명사를 바꾸거나 더할 때는 사전 쪽도 함께 본다.**

조회는 정확 일치 → 공백 무시 일치 → 트라이그램 유사도 순이다
(`find_cadence_prior`, `apps/ai` 의 `PriorsRepository.find`). 두 구현은 같은 규칙을
유지해야 한다.

## 빌드 산출물

`@lastly/contracts` 와 같은 이유다. 런타임 값이라 소스가 아니라 `dist` 의 JS 를 내보낸다.

```bash
pnpm --filter @lastly/parser build   # tsc -p tsconfig.build.json
```

turbo 의 `dependsOn: ["^build"]` 가 `api` · `web` 보다 먼저 돌게 한다.

---

## 테스트 위치

`apps/api/src/modules/capture/` 에 있다.

| | 무엇 |
|---|---|
| `utterance-rules.spec.ts` | 규칙 단위 |
| `utterance-rules.eval.spec.ts` | 평가셋 전체 정확도 |

파서를 고쳤으면 `pnpm --filter @lastly/api test` 를 돌린다.
이 패키지는 의존성이 없으므로 테스트도 DB·AI 없이 돈다.
